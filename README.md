# Arch 02 — Mamba &amp; State-Space Models

A deep technical dive into state-space model architectures for sequence modelling: the HIPPO framework and S4 diagonal SSMs, Mamba's selective state-space mechanism with input-dependent parameters and hardware-aware recurrent scans, Mamba-2's structured state-space duality (SSD) with linear attention, the parallel scan algorithm for fast training, RWKV's parallel recurrence formulation, and an honest comparison of where SSMs outperform transformers and where they fall short in practice.
